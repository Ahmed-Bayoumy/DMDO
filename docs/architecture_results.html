Testing the MDO architectures#

This page records how the architectures added next to the default NHATC coordination were verified: hierarchical ATC (DIST: {IDF: ATC}, [Tosserams et al., 2006]), monolithic MDF (MON: MDF) and the MDA solvers that MDF uses (MDO architectures). The NHATC benchmark results are on Benchmarking and are unchanged.

The unit and integration tests are in tests/test_mdo_architectures.py. The SBJ runs below are single runs from the Table 1 reference design of Tosserams et al. [Tosserams et al., 2010], not a multi-start campaign.

Default architecture unchanged#

The default DIST: {IDF: NHATC} path, and every older problem file whose architecture value is not a known path (for example IDF), runs exactly as before: all seven recorded golden traces (tests/golden) are reproduced bit for bit with the new architectures in place. The traces were compared, not re-recorded.

MDA feedback detection and solvers#

The Sellar analyses [Sellar et al., 1996] at \(x = 1\), \(z = (5, 2)\), both in one MDA, form one feedback loop (\(y_1\) from DA1 feeds DA2, \(y_2\) from DA2 feeds DA1). Each solver converges it to the same couplings, \(y = (25.58830, 12.05849)\), with tolerance \(10^{-10}\) from \(y = (1, 1)\):

  • listing the loop’s analyses in either order gives the same couplings;

  • Newton converges a vector coupling \(y = A y + b\);

  • a loop that does not converge within maxiter is reported as not converged.

Monolithic MDF on Sellar#

examples/sellar_mdf.yaml: one standalone subproblem whose MDA holds both analyses, SLSQP as the optimizer, from \(x = 1\), \(z = (5, 2)\). The best known solution is \(f^\ast = 3.18339\) at \(x = 0\), \(z = (1.9776, 0)\) [Tedford and Martins, 2010].

All three end feasible with \(x = 0\), \(z_2 = 0\), \(y_1 = 3.16\) and \(y_2 = 3.75528\). With OMADS (solver: mads, 2000 evaluations, Newton MDA) instead of SLSQP the run reaches \(f = 3.183398\) at \(z_1 = 1.97764\).

The Newton solver ends every MDA with a fixed-point update \(y \leftarrow F(y)\), as Gauss–Seidel and Jacobi do. Without it, the optimizer’s finite-difference steps (about \(10^{-8}\)) changed the couplings by less than the MDA tolerance, Newton returned the warm-start couplings unchanged, the gradient vanished and SLSQP stopped at the start point (\(f = 23.04\)).

The tests also check that subproblems linked to each other are rejected under MDF, that MDF has no ask/tell loop, and that an MDA.solver key is ignored by the other architectures.

Hierarchical ATC#

Tree construction#

The tree is built from the subproblem links and the is_main subproblem. The tests cover a star, a chain rooted at a middle subproblem (the SBJ (d) layout), a four-level chain and list links. They also check that DMDO rejects a cycle (the geometric-programming problem’s links 1–2, 1–3, 2–3), a sibling link, a subproblem outside the tree, two is_main subproblems and a link to a subproblem that is not part of the run.

Analytical star#

A root with two children: the root owns copies of \(a\) and \(b\) and minimises \((a - b)^2\); child 2 minimises \((a - 3)^2\) with its copy of \(a\); child 3 minimises \((b + 1)^2\) with its copy of \(b\). The optimum is \(a^\ast = 5/3\), \(b^\ast = 1/3\), \(f^\ast = 16/3\). SLSQP in every subproblem; coordinator \(\beta = 1.2\), \(\gamma = 0.8\), single_multiplier_update: true.

  • ATC solves [SP1] -> [SP2, SP3] and reaches \(a = 1.666667\), \(b = 0.333333\), \(f = 5.3333333\) with a maximum inconsistency of \(5\times10^{-10}\) in 50 outer iterations.

  • On this star the level order equals the Gauss–Seidel order and the siblings share no pairs, so ATC and NHATC give identical runs.

  • Serial and parallel (process pool) ATC runs give identical results; with Session, each ask() returns one level ([1], then [2, 3]).

With the coordinator’s default double multiplier update per outer iteration, the same problem stalls at \(f \approx 5.37\): the penalty weight of one pair grows past \(10^{22}\) until SLSQP can no longer reduce its inconsistency (about \(4\times10^{-5}\)). Hence the recommendation to set single_multiplier_update: true for ATC.

Supersonic business jet#

The SBJ formulations (a) and (d) of Tosserams et al. [Tosserams et al., 2010] (Fig. 6) are trees and were solved with DIST: {IDF: ATC} and the unchanged settings of tests/SBJ/SBJ_a.yaml and SBJ_d.yaml (SLSQP subproblems, \(\beta = 1.03\), \(\gamma = 0.75\), stop when the maximum inconsistency is below \(10^{-3}\)). The final design was re-analysed with a converged MDA; the paper’s MDF optimum is \(W_t = 34.3\times10^3\) lb.
