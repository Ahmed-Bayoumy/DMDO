Subproblem solvers#

class DMDO.BaseSolver#

Bases: object

Default behaviour shared by solver strategies (see DMDO.ports.SubproblemSolver).

Strategies are stateless: per-subproblem state travels in SolverRequest.warm_start / SolverOutcome.warm_start, so a strategy instance can be shared, re-created on every solve, or run in another process.

Coordination policies#

class DMDO.CoordinationPolicy#

Base class of the coordination policies: decides how each multiplier update of the coordinator is scaled. Policies hold no state of their own; they read and write the coordinator they are given.

compute_scales(coord, iteration)#

Return (beta_scale, gamma_scale, budget_scale, event) for this outer iteration: the factor applied to the exponent of the penalty growth \(\beta\), the factor applied to the stall threshold \(\gamma\), the factor applied to the inner evaluation budget of the next outer iteration, and a flag that custom policies return as False. All factors are 1 in the base class.

multiplier_scales(coord, iteration)#

Called by the coordinator before each update: evaluates compute_scales() and records the applied factors. Returns (beta_scale, gamma_scale, event).

class DMDO.NeutralPolicy#

The none policy: the update of Background, unchanged.

DMDO.policy_for(coord)#

The policy of a coordinator: the one named by its adaptation_policy option, none by default.
