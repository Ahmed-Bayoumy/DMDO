class DMDO.service.Client(url, token=None, timeout=60.0)#

Bases: object

Connect to a DMDO service started with dmdo serve (or DMDO.service.serve()).

client = Client("http://localhost:8400", token="...")
session = client.create_session(setup_file="problem.yaml", mdo_name="wing",
                                blackboxes={"A1": "my_pkg.aero:A1"}, sweep="jacobi")
for event in session.run().events(): ...
Parameters:

  • url (str)

  • token (str | None)

  • timeout (float)

create_session(setup=None, setup_file=None, mdo_name='MDO', blackboxes=None, **options)#

Create a session from a problem definition dict (setup) or a YAML path readable by the service.

blackboxes maps names to "module:attr" import paths resolved by the service (and its workers). options: mode, sweep, executor ("inprocess", "process" or "remote"), placement ({subproblem index: worker tag}, implies executor="remote") and max_workers.

class DMDO.service.DMDOService(root_dir='dmdo_service', token=None, lease_seconds=None)#

Bases: object

Holds the sessions and the job queue; transport-independent (the HTTP handler below calls it).

Parameters:

  • root_dir (str) – each session works in <root_dir>/<session id>.

  • token (str | None) – shared secret clients and workers must send; None disables authentication.

  • lease_seconds (float | None) – re-offer a claimed job to another worker after this long without a result (None: never).

class DMDO.service.RemoteExecutor(queue, placement=None, timeout=None, max_workers=None)#

Bases: object

Executor whose tasks run on remote workers connected to a TaskQueue.

Parameters:

  • queue (TaskQueue) – the queue workers claim jobs from (the service’s queue).

  • placement (Mapping[Any, str] | None) – {subproblem index: worker tag}; tasks of other subproblems go to any worker.

  • timeout (float | None) – seconds to wait for one map call (None: no limit).

  • max_workers (int | None)

class DMDO.service.TaskQueue(lease_seconds=None)#

Bases: object

Thread-safe job queue between executors (producers) and HTTP workers (consumers).

Parameters:

lease_seconds (float | None) – a claimed job whose result has not arrived after this many seconds is offered again (a worker that died mid-job); None disables re-delivery.
