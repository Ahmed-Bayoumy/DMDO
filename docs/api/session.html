Session#

class DMDO.Session(mdo, *, mode=None, sweep=None, executor=None, max_workers=None, observers=(), resume=False, file=None)#

Bases: object

Build and drive one DMDO coordination run.

Parameters:

  • mdo (MDO) – the problem (built with from_yaml(), from_dict(), from_checkpoint() or by hand).

  • mode (str | None) – "serial" (Gauss-Seidel, in-process) or "parallel" (Jacobi, process pool) defaults; default: the coordinator’s mode from the problem definition.

  • sweep (str | None) – "gauss_seidel" or "jacobi", overriding mode.

  • executor (Any) – executor used by run() and step() (an Executor or a registered name); not used by ask/tell.

  • max_workers (int | None) – worker count for executors created from a name.

  • observers (Iterable[Any]) – extra RunObserver objects.

  • resume (bool) – continue a checkpointed run (see from_checkpoint()).

  • file (str | None)

property iteration: int#

Number of completed outer iterations (including those before a resumed checkpoint).

request_stop()#

End the run after the current outer iteration (thread-safe).

Return type:

None

ask()#

The subproblem tasks to solve next ([] once the run is over).

Tasks of one batch are independent (Jacobi: every subproblem; Gauss-Seidel: one subproblem at a time). Calling ask again before tell returns the same batch.

Return type:

List[SubproblemTask]

tell(results)#

Hand back the results of the last ask() batch (any order).

Returns the IterationRecord when these results completed an outer iteration, else None.

Parameters:

results (Sequence[SubproblemResult])

Return type:

IterationRecord | None

DMDO.main(options)#

Build and run a problem from a YAML file, as in earlier releases. options is a dictionary with the keys setup_file, mdo_name, working_dir, and optionally run_mode ("run" or "build"), exec_mode ("serial" or "parallel"), is_resume with restart_file (resume from a checkpoint), and blackboxes (name -> callable or discipline). Returns the MDO object.

mdo = main({"setup_file": "problem.yaml", "mdo_name": "wing", "working_dir": "runs",
            "blackboxes": {"A1": aero, "A2": structures}})
