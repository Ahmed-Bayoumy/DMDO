The Session API#

Session is the entry point for driving DMDO from other code. It builds a problem and drives its coordination loop in three ways, which can be mixed within one run:

run()

to the end, with the session’s executor;

step()

one outer iteration at a time, returning an IterationRecord;

ask() / tell(results)

the caller solves the subproblem tasks itself and hands the results back.

All three execute the same coordination code, so they produce identical results.

The example#

examples/session_basics.py runs the basic problem (8 outer iterations, for a quick demonstration) in the three ways:

import os

from basic_disciplines import BLACKBOXES

from DMDO import RunObserver, Session, load_setup, solve_task

HERE = os.path.dirname(os.path.abspath(__file__))
SETUP = os.path.join(HERE, "basic_problem.yaml")
WORK = os.path.join(HERE, "_runs")


class Progress(RunObserver):
  """Receives one IterationRecord per outer iteration (could push to a dashboard or a message queue)."""

  def on_iteration_end(self, run, record):
    print(f"  [observer] iteration {record.iteration}: objective={float(record.objective):.6f} "
          f"max|q|={record.max_inconsistency:.3e}")


def main():
  data = load_setup(SETUP)
  data["coord"]["c1"]["budget"] = 8   # problem definitions are plain dictionaries: adjust before building
  data["MDO"]["display"] = False     # no per-iteration console lines

  # 1. Run to the end.
  result = Session.from_dict(data, working_dir=WORK, mdo_name="run", blackboxes=BLACKBOXES).run()
  print(f"run():  {result.status}, {result.iterations} iterations, objective {result.objective}, "
        f"max|q| {result.max_inconsistency:.3e} ({result.stop_reason})")

  # 2. One outer iteration at a time, with an observer.
  with Session.from_dict(data, working_dir=WORK, mdo_name="step", blackboxes=BLACKBOXES,
                         observers=[Progress()]) as session:
    while (record := session.step()) is not None:
      if record.max_inconsistency < 3e-2:
        session.request_stop()          # e.g. an outer driver decides it is good enough
    print(f"step(): stopped after {session.iteration} iterations ({session.result().stop_reason})")

  # 3. ask/tell: the caller solves the subproblems (here in-process; could be another framework or a cluster).
  with Session.from_dict(data, working_dir=WORK, mdo_name="asktell", blackboxes=BLACKBOXES,
                         sweep="jacobi") as session:
    while not session.done:
      tasks = session.ask()                       # independent tasks: solve them anywhere, in any order
      results = [solve_task(task) for task in tasks]
      session.tell(results)
    print(f"ask/tell (Jacobi): objective {session.result().objective}")


if __name__ == "__main__":
  main()

Building a session#

Session.from_yaml("problem.yaml", working_dir="runs", blackboxes={...})   # name defaults to the file name
Session.from_dict(data, working_dir="runs", mdo_name="wing", blackboxes={...})
Session.from_checkpoint("runs/wing_post/coord_chk.pkl")                    # resume an interrupted run
Session(mdo)                                                               # an MDO built with the Python API

Problem definitions are plain dictionaries: load_setup() reads a YAML file into one, which can be edited before building (data["coord"]["c1"]["budget"] = 8 above). Keyword options select the sweep and the executor (mode=, sweep=, executor=, max_workers=) and add observers (observers=).

Stepping and stopping#

step() runs one outer iteration and returns its IterationRecord (iteration number, objective, maximum inconsistency, largest penalty weight, change of the design, worst link), or None once the run is over. request_stop() ends the run after the current outer iteration; it is safe to call from another thread. In the example, the inconsistency falls below \(3\times10^{-2}\) at iteration 2, so the run stops after iteration 3 with the reason "Stopped on request".

Observers#

An observer receives the hooks of the coordination loop (Implementation lists them in order). Subclass RunObserver and override the hooks you need, or pass any object that defines some of them:

import json
from DMDO import RunObserver

class JsonLines(RunObserver):
    """Append one JSON line per outer iteration, e.g. for a dashboard."""

    def __init__(self, path):
        self.path = path

    def on_iteration_end(self, run, record):
        with open(self.path, "a") as fh:
            fh.write(json.dumps({"iteration": record.iteration, "objective": float(record.objective),
                                 "max_inconsistency": record.max_inconsistency}) + "\n")

session = Session.from_yaml("problem.yaml", observers=[JsonLines("progress.jsonl")], blackboxes={...})

ask and tell#

ask() returns the subproblem tasks that can be solved now: one at a time with the Gauss–Seidel sweep, all subproblems at once with the Jacobi sweep. Each task is a self-contained SubproblemTask; DMDO.solve_task() solves it, here or anywhere else (another framework’s evaluator, a cluster, a remote service). tell(results) accepts the results in any order and returns the iteration record when the results completed an outer iteration.

from DMDO import solve_task

while not session.done:
    tasks = session.ask()
    results = [solve_task(task) for task in tasks]     # solve them wherever you like
    record = session.tell(results)
    if record is not None:
        print(record.iteration, record.max_inconsistency)

Serial, parallel and custom execution solves the tasks in a process pool.

Results#

session.result() returns a RunResult: the status (created, running, finished, failed, closed), the stopping reason, the number of outer iterations, the objective of the master subproblem, the maximum inconsistency, whether the master subproblem is feasible, every variable copy ("<name>_<subproblem>") and the list of iteration records. result.to_dict() converts everything to plain JSON-ready values.

Checkpoints and resume#

Every run writes coord_chk.pkl at the start of each outer iteration after the first. A session resumed from it continues at the checkpointed iteration and ends with exactly the same result as an uninterrupted run:

session = Session.from_checkpoint("runs/wing_post/coord_chk.pkl")
result = session.run()
print(result.iterations)   # counts the iterations before the checkpoint too
